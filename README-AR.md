# مُذَكِّرنا — تطبيق Android أونلاين

هذا مشروع Android بسيط يفتح موقع مُذَكِّرنا داخل التطبيق باستخدام WebView، بحيث يظهر كتطبيق مستقل بأيقونة على الهاتف. يحتاج إلى اتصال بالإنترنت، ويظل معتمدًا على توفر الموقع والخدمات الخلفية وقاعدة البيانات.

## بناء APK باستخدام Android Studio

1. نزّل وثبّت Android Studio على كمبيوتر.
2. فك ضغط مجلد `muzakkirna-android.zip`.
3. من Android Studio اختر **Open** وافتح مجلد `muzakkirna-android`.
4. وافق على مزامنة Gradle وثبّت Android SDK Platform 35 إذا طُلب منك.
5. من القائمة اختر **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. بعد انتهاء البناء اختر **Locate**. ملف APK التجريبي يكون عادة داخل `app/build/outputs/apk/debug/app-debug.apk`.
7. انقل الملف إلى هاتف Android وثبّته، مع السماح بالتثبيت من هذا المصدر عند طلب ذلك.

## ملاحظات مهمة

- رابط الموقع مضبوط في `MainActivity.java` داخل المتغير `APP_URL`.
- لم يتم بناء APK داخل هذه البيئة؛ الملف المرفق هو مصدر مشروع Android وليس APK جاهزًا.
- يجب التأكد أن رابط المعاينة والخدمات الخلفية ستظل متاحة للاستخدام الدائم. رابط المعاينة قد يكون مؤقتًا؛ الأفضل نشر الموقع على استضافة دائمة قبل الاعتماد على التطبيق.
- هذا الغلاف لا يحوّل وظائف الخادم إلى وظائف محلية، ولا يضمن إشعارات Android الأصلية أو الإشعارات في الخلفية.
- قبل نشر التطبيق على Google Play، راجع إعدادات الأمان والخصوصية والأيقونة والتوقيع وسياسات المتجر.
